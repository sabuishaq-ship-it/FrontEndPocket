# 📱 FrontEndPocket — تطبيق تعليم تطوير الواجهات الأمامية

![Android CI/CD](https://github.com)

تطبيق أندرويد تعليمي متكامل لتعلم تقنيات تطوير الويب (**HTML, CSS, JavaScript, Bootstrap, React**)، مبني بلغة **Java** وقاعدة بيانات محلية **SQLite**.

---

## ⚙️ مهارات بيئة العمل الحديثة والأتمتة المطبّقة (DevOps & CI/CD)

تم تجهيز هذا المشروع وفق أحدث معايير هندسة البرمجيات الحديثة:

* **إدارة النسخ السحابية (Git & GitHub):** هيكلة المستودع وعزل ملفات البناء المؤقتة والمفاتيح السرية عبر `.gitignore`.
* **التكامل المستمر (CI - GitHub Actions):** فحص تلقائي لجودة الكود (`Gradle Lint`) وتشغيل الاختبارات (`Unit Tests`) عند كل تعديل (`push`).
* **إدارة الأسرار وأمن المعلومات (GitHub Secrets):** تخزين مفاتيح التوقيع الرقمي وكلمات المرور بشكل مشفر وآمن بعيداً عن الكود المصدري.
* **التسليم المستمر والتوقيع الرقمي الآلي (CD & Signing):** بناء نسخة الإنتاج (`Release APK`) وتوقيعها رقمياً (`zipalign` & `apksigner`) ونشرها تلقائياً.

---

## 📥 تحميل التطبيق (Signed Release APK)
يمكنك تحميل أحدث نسخة موقّعة وجاهزة للتثبيت مباشرة على هواتف أندرويد من خلال:
1. قسم **[Releases](../../releases)** في يمين الصفحة.
2. أو من تبويب **[Actions](../../actions)** ⬅ آخر عملية ناجحة ⬅ قسم **Artifacts** (`FrontEndPocket-Signed-Release`).
